# Dataset Understanding

I downloaded this dataset from Kaggle, and it is called the Global Superstore dataset.

It contains information about orders, customers, products, sales, profit, discounts, and shipping.

After looking through the data, I understood that each row represents one customer order.

The Customer ID and Customer Name columns help identify each customer.

The Product ID and Product Name columns show which product was purchased.

The Sales and Profit columns help measure how well the business is performing.

The Country, State, City, and Region columns can be used to compare sales across different locations.

Overall, this dataset can help analyse sales trends and customer buying behaviour.

The three business questions I find most interesting are: Which products earn the highest profit? Which regions have the highest sales? And how do discounts affect profit?
